## ¿Qué es Nmap?

Nmap (Network Mapper) es la herramienta de escaneo de redes más utilizada en pentesting. Permite descubrir hosts activos, puertos abiertos, versiones de servicios y ejecutar scripts NSE.

## Escaneos básicos

```bash
# Escaneo estándar
nmap -sV -sC -oN scan.txt <IP>

# Todos los puertos
nmap -p- --open -T4 -n <IP>

# Sigiloso SYN scan
sudo nmap -sS -p- --min-rate 5000 <IP>
```

## Flags importantes

| Flag | Descripción |
|------|-------------|
| `-sV` | Detección de versiones |
| `-sC` | Scripts NSE por defecto |
| `-O`  | Detección de OS |
| `-A`  | Todo + traceroute |
| `-p-` | Todos los 65535 puertos |
| `-T4` | Velocidad agresiva |
| `-oN` | Output normal |
| `-oG` | Output grepeable |

## Scripts NSE útiles

```bash
# SMB
nmap --script smb-enum-shares,smb-enum-users -p 445 <IP>

# HTTP vulns
nmap --script http-vuln* -p 80,443 <IP>
```

## Workflow de reconocimiento

```bash
# 1. Descubrir hosts activos
nmap -sn 192.168.1.0/24

# 2. Todos los puertos rápido
nmap -p- --open -T4 -n -Pn <IP> -oG allports.txt

# 3. Detallado en puertos encontrados
nmap -sCV -p 22,80,443 <IP> -oN targeted.txt
```

> Usa Nmap solo en sistemas con autorización explícita.
