## ¿Qué es Shodan?

Shodan es un motor de búsqueda especializado en dispositivos conectados a internet. A diferencia de Google — que indexa contenido web — Shodan indexa **banners de servicios de red**: la respuesta que un servidor devuelve cuando te conectas a un puerto.

Cada pocos días, Shodan escanea toda la IPv4 pública, se conecta a miles de puertos en cada IP, y almacena las respuestas. El resultado es una base de datos que en tiempo real muestra qué está expuesto en internet y cómo está configurado.

### Qué encuentra Shodan

- Servidores web, FTP, SSH, Telnet, RDP
- Bases de datos expuestas (MongoDB, Elasticsearch, Redis, MySQL)
- Cámaras IP, routers, switches, puntos de acceso WiFi
- Sistemas SCADA e ICS (infraestructura crítica)
- Dispositivos IoT: smart TVs, impresoras, NAS, termostatos
- Servicios cloud mal configurados
- Certificados SSL y su contenido

> Shodan no hackea nada — muestra lo que ya está público. Usarlo para reconocimiento pasivo es legal. Explotar lo que encuentras sin autorización no lo es.

## 1. Interfaz web y búsquedas básicas

La cuenta gratuita en [shodan.io](https://shodan.io) da acceso limitado pero suficiente para empezar. Con la API key gratuita puedes hacer consultas desde la CLI y scripts Python.

### Búsqueda simple

Cualquier texto en la barra de búsqueda compara contra los banners almacenados:

```
apache
nginx
"220 FTP server ready"
"MongoDB"
"Redis"
```

### Campos principales en los resultados

Cada resultado de Shodan muestra:

| Campo | Descripción |
|-------|-------------|
| IP | Dirección IP pública |
| Hostname | Nombre de host (si existe) |
| Org | Organización propietaria del bloque IP |
| ASN | Número de sistema autónomo |
| Port | Puerto escaneado |
| Transport | TCP o UDP |
| Product | Nombre del producto/servicio |
| Version | Versión del servicio |
| OS | Sistema operativo detectado |
| Banner | Respuesta completa del servicio |
| Country | País de la IP |
| City | Ciudad aproximada |
| SSL | Información del certificado (si aplica) |

## 4. Shodan CLI

La línea de comandos es la forma más eficiente de trabajar con Shodan en un engagement.

### Instalación y configuración

```bash
# Instalar
pip3 install shodan

# Configurar API key (gratuita en shodan.io/account)
shodan init TU_API_KEY

# Verificar créditos disponibles
shodan info
```

### Comandos principales

```bash
# Buscar y mostrar resultados
shodan search "org:Example Corp"

# Limitar campos mostrados
shodan search --fields ip_str,port,org,hostname "nginx"
shodan search --fields ip_str,port,transport,product,version "org:Example Corp"

# Limitar número de resultados
shodan search --limit 100 "org:Example Corp"

# Guardar en CSV
shodan search --fields ip_str,port,product,version "org:Example Corp" > results.csv

# Información detallada de una IP
shodan host 93.184.216.34

# Historial de una IP (cambios a lo largo del tiempo)
shodan host --history 93.184.216.34

# Contar resultados sin mostrarlos
shodan count "org:Example Corp"

# Descargar resultados en JSON (consume créditos)
shodan download --limit 1000 output.json.gz "org:Example Corp"

# Convertir JSON descargado a CSV
shodan convert output.json.gz csv

# Parsear el JSON descargado
shodan parse --fields ip_str,port,org output.json.gz

# Estadísticas de una búsqueda
shodan stats --facets country,port "nginx"
```

### Alertas y monitoreo

```bash
# Crear alerta para monitorear una red
shodan alert create "Mi Red" 93.184.216.0/24

# Listar alertas activas
shodan alert list

# Ver triggers disponibles
shodan alert triggers

# Eliminar alerta
shodan alert remove ALERT_ID
```

### Domain lookup

```bash
# Información de un dominio (IPs, subdominios, etc.)
shodan domain example.com

# IPs asociadas al dominio
shodan domain example.com | grep "IPs:"

# Tags del dominio
shodan domain example.com | grep "Tags:"
```

### Búsquedas básicas

```python
import shodan
import json

api = shodan.Shodan("TU_API_KEY")

def search_shodan(query, limit=100):
    """Búsqueda paginada en Shodan"""
    results = []
    try:
        # Contar total primero
        total = api.count(query)
        print(f"[*] Total de resultados: {total['total']}")

        # Buscar con paginación
        for page in range(1, (limit // 100) + 2):
            batch = api.search(query, page=page)
            results.extend(batch['matches'])
            if len(results) >= limit:
                break

    except shodan.APIError as e:
        print(f"[-] Error: {e}")

    return results[:limit]

# Uso
resultados = search_shodan('org:"Example Corp"')

for r in resultados:
    print(f"""
IP:       {r['ip_str']}
Puerto:   {r['port']}
Org:      {r.get('org', 'N/A')}
OS:       {r.get('os', 'Desconocido')}
Producto: {r.get('product', '')} {r.get('version', '')}
Hostname: {', '.join(r.get('hostnames', []))}
""")
```

### Información detallada de una IP

```python
def host_info(ip):
    """Obtiene toda la información de una IP en Shodan"""
    try:
        host = api.host(ip)

        print(f"\n{'='*50}")
        print(f"IP: {host['ip_str']}")
        print(f"Organización: {host.get('org', 'N/A')}")
        print(f"OS: {host.get('os', 'N/A')}")
        print(f"País: {host.get('country_name', 'N/A')}")
        print(f"Ciudad: {host.get('city', 'N/A')}")
        print(f"ISP: {host.get('isp', 'N/A')}")
        print(f"ASN: {host.get('asn', 'N/A')}")
        print(f"Última actualización: {host.get('last_update', 'N/A')}")
        print(f"\nServicios encontrados ({len(host['data'])}):")

        for service in host['data']:
            print(f"\n  Puerto: {service['port']}/{service.get('transport', 'tcp')}")
            print(f"  Producto: {service.get('product', '?')} {service.get('version', '')}")
            if 'http' in service:
                print(f"  Título HTTP: {service['http'].get('title', '')}")
            if 'ssl' in service:
                cert = service['ssl'].get('cert', {})
                subject = cert.get('subject', {})
                print(f"  SSL CN: {subject.get('CN', 'N/A')}")
            print(f"  Banner: {service['data'][:150].strip()}")

    except shodan.APIError as e:
        print(f"[-] Error: {e}")

host_info("93.184.216.34")
```

### Reconocimiento completo de una organización

```python
import shodan
import json
import csv
from datetime import datetime

api = shodan.Shodan("TU_API_KEY")

def recon_organization(org_name, output_file="recon_output"):
    """Reconocimiento completo de una organización en Shodan"""

    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    results = {
        "organization": org_name,
        "timestamp": timestamp,
        "services": [],
        "vulnerabilities": [],
        "open_ports": {},
        "products": {},
        "countries": {}
    }

    try:
        query = f'org:"{org_name}"'
        total = api.count(query)
        print(f"[*] Organización: {org_name}")
        print(f"[*] Servicios expuestos: {total['total']}")

        # Estadísticas por facetas
        stats = api.count(query, facets=[
            ("port", 20),
            ("product", 15),
            ("country", 10),
            ("os", 5)
        ])

        print("\n[*] Top puertos:")
        for port_data in stats['facets']['port'][:10]:
            port = port_data['value']
            count = port_data['count']
            results['open_ports'][str(port)] = count
            print(f"    {port:5} → {count} instancias")

        print("\n[*] Top productos:")
        for prod_data in stats['facets']['product'][:10]:
            prod = prod_data['value']
            count = prod_data['count']
            results['products'][prod] = count
            print(f"    {prod} → {count}")

        # Buscar resultados detallados
        print("\n[*] Recopilando servicios detallados...")
        for result in api.search_cursor(query):
            service = {
                "ip": result['ip_str'],
                "port": result['port'],
                "transport": result.get('transport', 'tcp'),
                "product": result.get('product', ''),
                "version": result.get('version', ''),
                "os": result.get('os', ''),
                "hostnames": result.get('hostnames', []),
                "org": result.get('org', ''),
                "timestamp": result.get('timestamp', ''),
            }

            # Detectar vulns si están disponibles
            if 'vulns' in result:
                for cve, vuln_data in result['vulns'].items():
                    results['vulnerabilities'].append({
                        "ip": result['ip_str'],
                        "port": result['port'],
                        "cve": cve,
                        "cvss": vuln_data.get('cvss', 'N/A'),
                        "summary": vuln_data.get('summary', '')[:100]
                    })

            results['services'].append(service)

        # Guardar en JSON
        json_file = f"{output_file}_{timestamp}.json"
        with open(json_file, 'w') as f:
            json.dump(results, f, indent=2, default=str)
        print(f"\n[+] Resultados guardados: {json_file}")

        # Guardar CSV de servicios
        csv_file = f"{output_file}_{timestamp}.csv"
        with open(csv_file, 'w', newline='') as f:
            if results['services']:
                writer = csv.DictWriter(f, fieldnames=results['services'][0].keys())
                writer.writeheader()
                writer.writerows(results['services'])
        print(f"[+] CSV guardado: {csv_file}")

        # Mostrar vulnerabilidades encontradas
        if results['vulnerabilities']:
            print(f"\n[!] VULNERABILIDADES DETECTADAS: {len(results['vulnerabilities'])}")
            for vuln in results['vulnerabilities'][:10]:
                print(f"    {vuln['ip']}:{vuln['port']} → {vuln['cve']} (CVSS: {vuln['cvss']})")

    except shodan.APIError as e:
        print(f"[-] Error API: {e}")

    return results

# Uso
recon_organization("Example Corp", "example_corp_recon")
```

### Shodan + Python + Notificaciones

```python
import shodan
import smtplib
from email.mime.text import MIMEText

api = shodan.Shodan("TU_API_KEY")

def monitor_and_alert(query, email_to):
    """Monitoriza una búsqueda y envía alertas por email"""
    results = api.search(query)

    if results['total'] > 0:
        body = f"Shodan Alert: {results['total']} resultados para:\n{query}\n\n"
        for r in results['matches'][:5]:
            body += f"- {r['ip_str']}:{r['port']} ({r.get('org','N/A')})\n"

        msg = MIMEText(body)
        msg['Subject'] = f"[Shodan Alert] {query}"
        msg['From'] = "recon@tudominio.com"
        msg['To'] = email_to

        # Enviar
        with smtplib.SMTP('localhost') as s:
            s.send_message(msg)

        print(f"[+] Alerta enviada a {email_to}")
```

## 10. Cheatsheet de referencia rápida

```bash
# ── CLI ─────────────────────────────────────────────────
shodan init TU_API_KEY                            # Configurar
shodan search "org:Example Corp"                  # Buscar
shodan search --fields ip_str,port "nginx"        # Campos específicos
shodan search --limit 100 "org:Example"           # Limitar resultados
shodan host 93.184.216.34                         # Info de IP
shodan count "org:Example Corp"                   # Contar sin mostrar
shodan domain example.com                         # Info de dominio
shodan stats --facets port,product "org:Example"  # Estadísticas

# ── FILTROS CLAVE ────────────────────────────────────────
org:"Example Corp"                  # Por organización
hostname:example.com               # Por hostname
net:93.184.216.0/24                # Por rango IP
port:22                            # Por puerto
product:"Apache httpd"             # Por producto
version:"2.4.49"                   # Por versión
country:ES                         # Por país
ssl.cert.subject.cn:example.com    # Por certificado SSL
http.title:"Dashboard"             # Por título HTTP
vuln:CVE-2021-44228                # Por CVE

# ── DORKS ÚTILES ─────────────────────────────────────────
org:"Example" port:3389                           # RDP expuesto
org:"Example" port:27017 -"authentication"        # MongoDB sin auth
port:9200 "{\"cluster_name\""                    # Elasticsearch
port:6379 "redis_version" -"NOAUTH"              # Redis sin pass
port:5900 "authentication disabled"              # VNC sin auth
http.title:"Kibana" port:5601                    # Kibana expuesto
http.title:"Jenkins" port:8080                   # Jenkins expuesto
http.title:"Jupyter" -"Password"                 # Jupyter sin pass
ssl.cert.expired:true org:"Example"              # Certificados caducados
vuln:CVE-2021-44228 org:"Example"                # Log4Shell


```
